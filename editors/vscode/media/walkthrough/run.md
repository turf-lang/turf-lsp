# Run it

With the Turf toolchain installed, press the **Run** button at the top right of
the editor, or the **Run** link above `main`, or run **Turf: Run** from the
command palette (**Ctrl+Shift+P**).

- In a project (a folder with `turf.toml`) this runs `turf run`.
- On a single file it runs that file.
- **Turf: Run Tests** runs the project's `tests/`, and shows each test in the
  Testing view.

Everything also shows up as a task (**Terminal → Run Task…**), so you can bind
it to a key or put it in `tasks.json`.
