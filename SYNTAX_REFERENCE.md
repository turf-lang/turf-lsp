# Turf Syntax Reference

## Keywords
- **Declarations**: `fn`, `mut`, `immut`, `struct`, `extern`, `from`
- **Control Flow**: `if`, `elseif`, `else`, `while`, `for`, `in`, `step`, `give`, `otherwise`, `break`, `continue`, `return`
- **Operators**: `to` (casting)

## Types
- `int`, `double`, `bool`, `string`, `ptr`, `void`

## Literals
- **Booleans**: `true`, `false`
- **Null**: `null`
- **Numbers**: Decimals (`42`, `3.14`)
- **Strings**: `"Hello, World!"`

## Builtins
- `assert`
- `io.printline` (standard library)

## Comments
- `// This is a comment`

## Special Symbols
- Variadic arguments: `...`
